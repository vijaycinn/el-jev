Core Savings Mechanism

  • Routing only (System-1 vs LLM router): ~17× to 26× faster (195–305 ms vs 3.84–5.12 s), with about ~50–235 input tokens + 1–3 output tokens per Decision-1 gate call versus ~180K+ full-workspace prompt tokens per LLM turn.
  • Sub-agent circuit-breaker: onPreToolUse blocks task on fast_direct turns, saving roughly 95.2 s median wall time plus multiple sub-agent LLM turns per prevented spawn, while keeping execution on direct view/grep/edit tools (66–131 ms p50).
